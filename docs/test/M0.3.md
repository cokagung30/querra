## Konteks untuk Claude

- M0.3 membangun shell (`frontend/src/app/`): sidebar, tab bar, area konten, panel Results, status bar, registry perintah (`src/lib/commands`), i18n (`src/i18n`), token desain dan warna environment (`src/index.css`), serta tema yang mengikuti sistem (`src/app/theme.ts`). Tab query masih placeholder sampai M2.3.
- **Menu native macOS** (`internal/app/menu.go`, dipasang di `main.go` hanya untuk darwin) berisi App, Edit, dan Window saja. Menu bawaan Wails sengaja tidak dipakai karena mengambil ⌘W (tutup jendela) dan ⌘R (reload webview). Kode ini **belum pernah dijalankan di macOS**, jadi B3, B8, dan B15 adalah pemeriksaan utamanya. Kalau gagal, perbaiki `menu.go`.
- Kalau ⌃Tab atau ⌃⇧Tab ternyata tidak sampai ke WKWebView, default `tab.next`/`tab.previous` di `src/app/commands.ts` perlu diganti, misalnya ke ⌘⇧] dan ⌘⇧[. Perbarui juga tesnya.
- Kode spike M0.2 sudah dihapus. Hook pengukuran pindah ke `PerfService` (`QUERRA_PERF_AUTORUN`). Di Windows ketiga mode (startup, idle, grid) sudah terbukti jalan; di macOS belum.
- **Setelah hasil masuk:** isi tabel di bawah, tambahkan angka macOS ke `docs/spikes/fase-0.md` §8, lalu centang M0.3 di `PLAN.md` bila semua platform ✅. Hapus juga catatan "menunggu uji manual di macOS" di baris M0.3.

## Persiapan (macOS)

```bash
git pull

go version        # harus go1.26.2. Kalau Go lokal lebih baru:
                  #   go env -w GOTOOLCHAIN=go1.26.2+auto
wails3 version    # harus v3.1.0. Kalau belum:
                  #   go install github.com/wailsapp/wails/v3/cmd/wails3@v3.1.0
node --version    # minimal 24

cd frontend && npm ci && cd ..   # dependensi berubah di M0.3
rm -f bin/querra                 # hanya perlu bila sebelumnya build universal
```

Fase ini belum memakai database, jadi `dev/test.env` dan `db:reset` tidak diperlukan.
