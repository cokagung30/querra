## Konteks untuk Claude

- M0.3 membangun shell (`frontend/src/app/`): sidebar, tab bar, area konten, panel Results, status bar, registry perintah (`src/lib/commands`), i18n (`src/i18n`), token desain dan warna environment (`src/index.css`), serta tema yang mengikuti sistem (`src/app/theme.ts`). Tab query masih placeholder sampai M2.3.
- **Menu native macOS** (`internal/app/menu.go`, dipasang di `main.go` hanya untuk darwin) berisi App, Edit, dan Window saja. Menu bawaan Wails sengaja tidak dipakai karena mengambil ⌘W (tutup jendela) dan ⌘R (reload webview). Sudah terbukti di macOS 26.6.2 (B3, B8, B15 ✅). Role App/Edit/Window di Wails v3.1.0 hanya membawa ⌘H, ⌥⌘H, ⌘Q, ⌘M, dan akselerator Edit.
- ⌃Tab dan ⌃⇧Tab sampai ke WKWebView (B5a, B5b ✅ di macOS), jadi default `tab.next`/`tab.previous` di `src/app/commands.ts` tetap.
- Kode spike M0.2 sudah dihapus. Hook pengukuran pindah ke `PerfService` (`QUERRA_PERF_AUTORUN`). Ketiga mode (startup, idle, grid) sudah terbukti jalan di Windows dan macOS.
- **Yang tersisa:** tujuh langkah Windows yang masih ⏳ (B5b, B7, B10, B12, B12b, B13, B14), plus B12b di macOS. B12b ditambahkan setelah code review 14 November (lihat **Temuan**). Setelah semuanya ✅, centang M0.3 di `PLAN.md`, hapus catatan "tinggal … di Windows" di baris M0.3, dan perbarui tabel di `README.md`.

## Persiapan (macOS)

```bash
git pull

go version        # harus go1.26.2. Kalau Go lokal lebih baru:
                  #   go env -w GOTOOLCHAIN=go1.26.2+auto
wails3 version    # harus v3.1.0. Kalau belum:
                  #   go install github.com/wailsapp/wails/v3/cmd/wails3@v3.1.0
node --version    # minimal 24

cd frontend && npm ci && cd ..   # dependensi berubah di M0.3
rm -f bin/querra                 # hanya perlu bila sebelumnya build universal
```

Fase ini belum memakai database, jadi `dev/test.env` dan `db:reset` tidak diperlukan.

## Persiapan (Windows)

Sudah diperbaiki di `AppShell.tsx` (saat mount, flag mengikuti panel yang dipulihkan) dan dikunci dengan tes di `App.test.tsx`. Tinggal dicek di aplikasi sungguhan lewat B12b.
