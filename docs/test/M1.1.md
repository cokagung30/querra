## Konteks untuk Claude

- M1.1 hanya menambah paket Go, tanpa UI dan tanpa perubahan di `main.go`: `internal/store` (SQLite lokal, migrasi, repositori `Groups`/`Connections`/`Settings`) dan `internal/secrets` (`Store`, `Keyring`, `Memory`). Layanan koneksi M1.3 yang nanti memakainya.
- Unit test berjalan di CI dengan fake dan provider mock go-keyring. Satu-satunya yang tidak bisa diuji otomatis adalah keychain sungguhan, jadi smoke test K1 dijalankan manual sekali per platform.
- Di macOS, go-keyring menjalankan `/usr/bin/security` (laporan spike §4.5). Smoke test seharusnya lulus tanpa dialog izin. Kalau muncul dialog, catat sebagai temuan, karena itu berarti pengguna juga akan melihatnya.
- **Setelah hasil masuk:** isi kolom macOS. Kalau semuanya ✅, centang M1.1 di `PLAN.md` (hapus catatan "menunggu smoke test keychain di macOS") dan perbarui tabel di `README.md`.
