| macOS | ⏳ | | T7 (ekspor/impor), lalu uji aplikasi sungguhan (B) |

## Konteks untuk Claude

- **Rencana dan desain:** PLAN M1.4, termasuk "Rencana pengerjaan M1.4" (T1–T8). Mockup arahnya ada di proyek Stitch "Querra – M1.4 Connection UI" (`1225370253316826263`).
- **Sudah dibuat di Windows (T1–T6), semuanya frontend; tidak ada perubahan Go:**
  - Dependensi baru: `@tanstack/react-query` 5.108, `@dnd-kit/core` 6.3.1, `@dnd-kit/sortable` 10.0.0, `@dnd-kit/utilities` 3.2.2.
  - Komponen shadcn baru: dialog, alert-dialog, tabs, input, label, select, switch, context-menu, dropdown-menu. Teks "Close" di `dialog.tsx` sekarang lewat `t()`.
  - `lib/apperr.ts` (`toAppError`, `errorText`) dan `lib/query.ts` (`queryClient`).
  - `stores/connections.ts`: pilihan, fokus daftar, dialog yang terbuka, konfirmasi hapus, dialog grup, dan error daftar.
  - `features/connections/`:
    - `api.ts`, `queries.ts`, `model.ts` (pengelompokan, filter, urutan baru, `passwordChange`), dan `commands.ts`.
    - `ConnectionList`/`ConnectionRow`: sidebar, drag & drop, menu klik kanan, dan menu ⋯.
    - `useArrange`: drop → `Arrange`/`ArrangeGroups`, dengan update optimistis dan rollback.
    - `ConnectionDialogs`: konfirmasi hapus, dialog nama grup, dan dialog koneksi yang dimuat lazy.
    - `ConnectionDialog`, `useConnectionForm`, dan `TestResultPanel`.
  - `lib/commands`: `isEnabled` sekarang menerima argumen perintah. `Delete` dari keyboard hanya aktif saat daftar difokus, sedangkan item menu menyebut koneksinya sendiri.
  - Token warna `--conn-<color>` (terang dan gelap) di `index.css`. Layar welcome mendapat tombol New Connection dan landmark "Welcome".
- **Keputusan selama pengerjaan:**
  - Pilihan grup di submenu *Move to Group* memakai jalur `useArrange` yang sama dengan drag & drop, bukan perintah tersendiri.
  - Field `invalid_input` dari Test maupun Save tampil di bawah kolomnya, dan dialog pindah ke tab kolom itu.
  - Engine tanpa host (SQLite) belum punya form khusus; itu bagian M4.2.
- **Sudah diverifikasi di Windows:**
  - Vitest 102/102, tsc, ESLint (hanya peringatan lama di PerfGrid), Prettier, dan `vite build`.
  - Pratinjau di Edge headless (Chromium, mesin yang sama dengan WebView2) dengan server Vite yang mengganti `api.ts` dengan data tiruan. Ada 17 pemeriksaan, semuanya lulus, tanpa error di console:
    - daftar, menu klik kanan dan submenunya, pindah grup lewat menu;
    - drag dengan mouse antar-grup, klik yang tidak memicu drag, drag dengan keyboard, dan drag grup;
    - `Delete` yang hanya aktif saat daftar difokus, `Ctrl+N`, dan Production yang menyalakan hanya-baca;
    - konfirmasi buang perubahan, klik ganda untuk Edit, tahap Test, dan password yang tetap `keep`.
  - Pratinjau ini bukan aplikasi Wails sungguhan dan tidak memakai backend asli. Skripnya hanya ada di scratchpad sesi itu.
- **Dampak ukuran:** JS saat startup naik dari 149 KB menjadi ±200 KB gzip, dan dialog koneksi (15 KB gzip) baru dimuat saat dibuka. Ukur startup dan memori di bagian **Pengukuran**.
- **Yang dikerjakan di Mac:**
  1. **T7 (ekspor/impor):**
     - Di Go: `ConnectionService.ExportFile(ctx, ids []string, path string) error` dan `ImportFile(ctx, path string) (connection.ImportResult, error)`, dengan tes file sementara. Lalu `wails3 task bindings`.
     - Di `api.ts`: `exportToFile(ids)` dan `importFromFile()`. Keduanya memilih path lewat `Dialogs.SaveFile`/`Dialogs.OpenFile` (nama bawaan `querra-connections.json`); path kosong berarti batal.
     - Di UI: item Import… dan Export All… di menu ⋯, Export… di menu koneksi dan menu grup, dialog hasil impor, dan error `invalid_file`. Semuanya didaftarkan sebagai perintah.
     - `PRIVACY.md` sudah mencakup file ekspor, jadi tidak perlu diubah.
  2. **T8:** jalankan bagian B di Mac lewat `EXTRA_TAGS=mcp wails3 dev` dengan PostgreSQL lokal, lalu `wails3 task lint` dan `wails3 task test`.
  3. **Build Store:** naikkan `Identity/@Version` di `build/windows/msix/app_manifest.xml` (mis. `0.1.1.0`). Setelah push dan CI hijau, pemilik mengunggah `querra-amd64.msix` ke draft *Product update* di Partner Center, lalu bagian C dijalankan di Windows.
- Setelah semua ✅, centang butir M1.4 yang tersisa dan M1.4 sendiri di PLAN, perbarui tabel di `README.md`, dan hapus catatan D3–D4 yang tertunda di `M0.5.md`.

## Persiapan (macOS)

```bash
git pull
cd frontend && npm ci && cd ..
wails3 task db:reset   # querra_test di PostgreSQL lokal (dev/test.env)
```
